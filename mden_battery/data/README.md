**Подготовка данных**

Основной путь нового ноутбука: `log_age.py` подготавливает KIT LOG_AGE и кеш v8; `window_batches.py` собирает batch без хранения всех окон. Контракт: 32×5 → следующие 8 SOC/SOH, stride 8, split по физическим батареям, scaler только по train.

`article_preprocessing.py` содержит отдельные функции для заранее приведённых к формату статьи данных с настоящими границами циклов. KIT EFC нельзя подставлять в них как эквивалент номера цикла MIT. `energystatus.py` и `streaming.py` сохранены для совместимости со старым API. Подробная семантика и ограничения описаны в `../../docs/AUDIT_RU.md` и `../../docs/PIPELINE_RU.md`.
